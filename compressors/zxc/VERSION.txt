zxc 1.0.0 (tag v1.0.0, commit d237221, 2026-11-11, format version 9, now frozen), copied
unmodified. Its C API changed (the level is a parameter of zxc_compress(), settings go
on a context; zxc_decompress() no longer verifies checksums, and zpaq-std never wrote
them): compressors/plug/zs_zxc.cpp follows it. Levels 1 to 7 write the bytes of 0.15.0.
What follows is the note of 0.15.0:

zxc 0.15.0 (tag v0.15.0, commit 2d29ab6, format version 9), from
https://github.com/hellobertrand/zxc. BSD 3-Clause, see LICENSE; lib/vendors/rapidhash.h
is rapidhash V3 by Nicolas De Carli, MIT (LICENSE-rapidhash). Files copied unmodified:
include/*.h, src/lib/*.c and *.h, src/lib/vendors/rapidhash.h (not the CLI).
zxc_compress.c, zxc_decompress.c and zxc_huffman.c are built three times, as zxc's
CMake does (_default, _avx2, _avx512 on x86), and zxc_dispatch.c picks one at run time.
Stable in zpaq-std (out of experimental since 2026-10-21). zxc is 0.x (format version 9); a later format gets a new decoder
(ZPAQZXC10, tag zxc10), and blocks written now keep theirs (ZPAQZXC).
